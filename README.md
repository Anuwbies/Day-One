# Day One: Survival 🏝️

A 2D top-down survival game built with Unity where players must survive on a deserted island after waking up with no memory and no supplies.

## 📖 Overview

After a night of heavy drinking, you wake up stranded on a remote island with no recollection of how you got there. With nothing but your wits and the resources around you, you must gather materials, craft tools, build shelter, and manage your survival stats to stay alive as long as possible.

## 🎮 Game Features

- **Top-down exploration** - Navigate a deserted island from a bird's-eye view
- **Resource gathering** - Collect wood, stone, plants, and food
- **Crafting system** - Create tools, weapons, and structures to aid survival
- **Day/night cycle** - Adapt to changing conditions as time passes
- **Survival management** - Monitor hunger, thirst, stamina, and health
- **Wildlife encounters** - Face dangerous animals and avoid threats
- **Inventory system** - Manage your equipment and collected resources

## 🎯 Objective

**Win Condition:** Survive for a set number of days or reach specific survival milestones

**Lose Condition:** Death from starvation, dehydration, wildlife attacks, or environmental exposure

## 🚀 Getting Started

### Prerequisites

- Unity 2021.3 LTS or later
- Git

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/day-one-survival.git
```

2. Open the project in Unity Hub
```
File > Open Project > Select the cloned folder
```

3. Wait for Unity to import all assets

4. Open the main scene and press Play to test

## 🎮 How to Play

- **Movement:** WASD or Arrow Keys
- **Interact:** E key
- **Inventory:** I key or Tab
- **Craft:** C key
- **Pause:** ESC

*(Adjust controls based on your actual implementation)*
